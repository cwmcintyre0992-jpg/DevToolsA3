# Portfolio Website

A static developer portfolio built with HTML, CSS and JavaScript, ready for GitHub Pages.

## Deploy on GitHub Pages

1. On GitHub, create a **public** repository named `YOUR-USERNAME.github.io` (or any name, e.g. `portfolio`).
2. Upload `index.html`, `style.css` and `script.js` to the repository root (Add file > Upload files).
3. Go to **Settings > Pages**. Under *Build and deployment*, set Source to **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
4. Wait a minute or two. Your site will be live at `https://YOUR-USERNAME.github.io/` (or `https://YOUR-USERNAME.github.io/portfolio/` for a project repo).
5. Submit that URL for the assignment.

## Make it yours

- Replace "Alex Morgan", the school names, emails and links with your own details.
- Replace each `href="#"` in the Projects section with your real GitHub or demo links.
- Update the "actual portfolio" link in the disclaimer banner at the top of `index.html`, or delete the whole `<div class="disclaimer">` block once marking is finished.
- Change colours in the `:root` block at the top of `style.css`.
